# Pack de assets e integración visual - Pueblo de Sombras

## Resumen ejecutivo

Se incorporó y organizó un pack integral de ambientación para la escena principal **Fase0-Escenario**, desarrollado para **Unity 6.3 LTS con Universal Render Pipeline (URP)**.

El contenido amplía el escenario con utilería urbana, vegetación, vehículos, campamentos, ruinas, elementos costeros, arquitectura modular, efectos visuales y sistemas atmosféricos. También se desarrollaron materiales, texturas, shaders e iluminación específicos para mantener una estética low-poly estilizada y coherente con el universo visual de *Pueblo de Sombras*.

El pack reúne más de **109 tipos nominales de elementos ambientales**, además de **283 prefabs**, variantes modulares y recursos complementarios.

## Materiales y texturas desarrollados

Se prepararon materiales coherentes con la dirección visual low-poly y con el pipeline URP:

- Veredas de hormigón rosado-gris.
- Asfalto desgastado.
- Cordones de hormigón.
- Muros de basalto con vegetación y musgo.
- Piedra costera con humedad, moho y residuos.
- Césped urbano.
- Centros de manzana con cuatro variantes.
- Tejas rojizas.
- Revoque de viviendas.
- Revoques atacados y deteriorados.
- Madera pintada para viviendas portuarias.
- Cinco variantes pastel para fachadas.
- Cinco variantes de madera portuaria.
- Cinco variantes de revoque portuario.
- Cinco variantes de superficies atacadas.
- Agua estilizada para el objeto AWA.
- Materiales de partículas violetas y ceniza.
- Material de relámpago.
- Material de neblina baja.
- Skybox apocalíptico panorámico.

Las texturas fueron preparadas con mapas compatibles con URP, incluyendo combinaciones de:

- Albedo o Base Color.
- Normal Map.
- Roughness y Smoothness.
- Metallic compatible.
- Variación superficial.
- Desgaste, suciedad y humedad.

También se corrigió la escala visual de los materiales para evitar patrones excesivamente pequeños en muros, calles, techos y veredas.

## Iluminación

La iluminación fue adaptada para representar una ciudad bajo ataque, manteniendo legibilidad nocturna:

- Iluminación urbana cálida mediante farolas.
- Contraste entre luces amarillas y focos de corrupción violetas.
- Luces azules, verdes y magenta para zonas afectadas.
- 36 fuentes violetas utilizadas como referencia atmosférica.
- 18 luces violetas con variación dinámica de intensidad.
- Luz direccional global fría y de baja intensidad.
- Destello global asociado a tormentas.
- Integración de bloom moderado para unificar fuentes emisivas.

## Atmósfera y efectos ambientales

Se incorporaron los siguientes sistemas:

- Skybox apocalíptico panorámico.
- Silueta de Encarnación integrada directamente en el horizonte del skybox.
- Niebla global en modo Exponential Squared.
- Nueve capas de neblina baja.
- Cuatro sistemas de ceniza ambiental.
- 36 sistemas de partículas vinculados a luces de corrupción.
- Motas violetas flotantes.
- Relámpagos visibles.

## Filtro visual

Se incorporó un volumen global de postprocesado denominado:

`Atmosfera_Filtro_Retro`

Incluye:

- Grano fino con intensidad 0,14.
- Viñeta suave con intensidad 0,16.
- Saturación en -9.
- Contraste en +6.
- Aberración cromática mínima.
- Balance de blancos sutil.
- Bloom moderado.
- Dithering para reducir bandas de color.

El efecto puede regularse desde la propiedad `Weight` del componente Volume.

## Recomendaciones de rendimiento

Antes de generar una versión definitiva se recomienda:

- Configurar el plano lejano de la cámara entre 400 y 500 unidades.
- Desactivar sombras en luces decorativas violetas.
- Reservar sombras para luces principales.
- Usar Direct3D11 en el editor si Direct3D12 presenta inestabilidad.
- Aplicar LOD a árboles, vehículos y arquitectura distante.
- Utilizar Occlusion Culling en sectores urbanos.
- Revisar el atlas de sombras de luces adicionales.
- Comprimir texturas según la plataforma de destino.
- Mantener las partículas ambientales dentro de límites visibles.
- Evaluar Static Batching para elementos inmóviles.

## Incorporación al repositorio

Se deben incluir:

- `Assets/Escenario`
- Todos los archivos `.meta`
- `Packages`
- `ProjectSettings`

No se deben incluir:

- `Library`
- `Temp`
- `Logs`
- `Obj`
- `UserSettings`
- Carpetas de crash o recuperación temporal

Para archivos pesados se recomienda utilizar Git LFS, especialmente para:

- FBX
- DAE
- PNG
- JPG y JPEG
- EXR
- Unitypackage
